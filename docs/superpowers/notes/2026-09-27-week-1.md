## Defects reproduced and corrected

- Board configuration was parsing status names, but Jira supplies status IDs.
  Fixtures now use the documented shape; the probe reports IDs and derives done IDs
  from the last column with mapped statuses.
- The Friday demo lacked the known issue link, saved-filter ID and estimate field.
  The probe now displays them and rejects Kanban or incomplete board evidence.
- Blank tokens, malformed hosts/cloud IDs, invalid timezones and out-of-project
  known issue keys were accepted. They now fail before network requests.
- Issue/board reads bypassed the declared pilot restriction; malformed JQL could
  escape its surrounding parentheses. Requests/results are checked, and the Week 1
  JQL helper explicitly accepts predicates only, without sorting.
- Network failures, malformed JSON/resources/search pages and malformed Retry-After
  headers could crash or imply false completeness. They now produce typed errors.
  Raw upstream errors are not echoed, and the probe no longer prints assignee names.
- README installation failed under zsh because `.[dev]` was unquoted; pre-commit
  was missing from dependencies and its Ruff repository was wrong. Setup is corrected.
- Tests now isolate all `SCRUM_AGENT_` environment variables as well as `.env`.
